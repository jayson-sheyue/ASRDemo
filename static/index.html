先搞懂它是什么，再点按钮。

这是一台云端速记员：你给声音，它交回文字。顶栏每一页是不同专长的速记员，控件和样例不能混着用。下面用大白话解释三种交货方式、新旧柜台，以及医学模型为什么只有美国英语。

它能干嘛

把短录音打成一篇稿，或对着麦克风边说边出字。会议纪要、字幕、客服留言、语音输入，都靠这个。

三种交货方式

「转写」= 整段交上去等全文（大约一分钟内）。「实时听写」= 边说边出字幕。更长的录音要过夜批量，工作台不做。

先做这三件事

① Chirp 3 转写「第一段中文」
② 再开「专有名词」看提示短语
③ 打开 Medical 页，确认语言只有 en-US

官方原生支持哪些能力？

核查日期 2026-09-10。不能克隆声纹、不能离线、医学模型不能听中文。

五个工作台怎么选？

Chirp 3 是默认。其余页是对照和专用场景。医学页只听美国英语。

同步转写 / 实时听写 / 批量转写

这不是三种模型，是三种把声音送上云的方式。官方接口名分别叫 Recognize、StreamingRecognize、BatchRecognize。

新柜台 V2 和旧柜台 V1

同一家服务的两代填表方式。新项目走 V2 + Chirp 3。医学模型目前仍在 V1，且只支持 en-US。

什么时候不选 Chirp 3？

电话、英语病历、已经上线的旧系统、超过一分钟还在云存储里的录音，各走各的路。

业务怎么选型？

先对场景，再进对应页听样例。定价以官方价目为准。中文病历不要进 Medical 页。

每个开关的业务价值

多开一个开关不等于更准。分轨样例用 2 轨或 4 轨，API 上限是 8 轨，不是只能双声道。

STT API 还有、本 Demo 不调用的能力

列出是为了选型和接入时不漏项。
